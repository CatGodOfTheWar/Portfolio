# My Portfolio Website

## Overview
This is my personal portfolio website showcasing my projects and skills. It includes sections about me, my projects, and contact information.

## Features
- **Responsive Design**: The website is fully responsive and works on various screen sizes.
- **Smooth Scrolling**: Smooth scrolling behavior for better user experience.
- **Interactive Elements**: Includes animations and interactive elements for better engagement.
- **Project Showcase**: Displays my projects with descriptions and links to source code.
- **Contact Section**: Provides a way to contact me via email.

## Technologies Used
- **HTML**: For the structure of the website.
- **CSS**: For styling the website.
- **JavaScript**: For adding interactivity and animations.
- **Google Fonts**: For custom fonts.
- **Icons8**: For icons used in the website.
